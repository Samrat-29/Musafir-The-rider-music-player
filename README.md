# 🏍️ मुसाफिर — THE RIDER

> **A journey is not just about the destination. It's about the road, the music, and the moments along the way.**

**Musafir — THE RIDER** is a cinematic motorcycle travel experience built around a full-screen immersive riding environment, combining a scenic motorcycle POV with an integrated music experience.

The project brings together **travel, music, and interactive web design** into one atmospheric experience.

---

## ✨ Features

### 🏔️ Cinematic Riding Experience

* Full-screen motorcycle POV experience
* Mountain-road/Ladakh-inspired environment
* Immersive visual presentation
* Minimal, distraction-free interface

### 🎵 Music Player

* Floating music player
* Play / Pause controls
* Previous / Next track
* Track information
* Album artwork
* Progress and playback information

### ▶️ YouTube Integration

* YouTube video URLs
* YouTube playlist URLs
* YouTube video IDs
* YouTube embed URLs
* Automatic YouTube ID extraction
* Playlist loading

### 🟢 Spotify Integration

* Spotify track URLs
* Spotify album URLs
* Spotify playlist URLs
* Spotify artist URLs
* Spotify metadata and artwork
* Spotify tracks integrated into the music system
* Support for mixed YouTube + Spotify music collections

### 📋 Playlist System

* Add tracks through URLs
* Create a personal music collection
* Switch between tracks
* Previous / Next navigation
* Mixed-source playlists

### 👥 Real-Time Online Counter

* Displays the number of users currently online
* Real-time presence updates
* Automatic connection/disconnection handling
* Anonymous session-based presence

### 🎨 Visual Design

* Dark glassmorphism UI
* Minimal controls
* Cinematic typography
* Responsive layout
* Floating bottom-right music interface
* Small **मुसाफिर — THE RIDER** branding

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Samrat-29/Musafir-The-rider-music-player.git
```

### 2. Enter the project

```bash
cd Musafir-The-rider-music-player
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

## 🔐 Environment Variables

```text
YouTube embed URL
```

### Spotify

Supported:

```text
Spotify album
Spotify playlist
```
